# 📡 News Bot

بوت Telegram لمتابعة الأخبار العاجلة من 6 قنوات إخبارية كل 10 دقائق.

**يعمل 24/7 مجاناً على GitHub Actions.**

## التثبيت

1. **انشر هذا المجلد** على GitHub repository
2. **أضف Secrets** في `Settings → Secrets and variables → Actions`:
   - `TELEGRAM_TOKEN` — توكن بوت Telegram
   - `CHAT_ID` — رقم محادثتك في Telegram
   - `GEMINI_KEY` — مفتاح Google Gemini API
3. **فعّل Actions** من تبويب `Actions` في الـ repo

## المواضيع المتابعة

- إيران-إسرائيل
- فلسطين وغزة
- روسيا-أوكرانيا
- أمريكا والوطن العربي
